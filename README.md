## 🚀 Getting Started Locally

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/akshreyagupta28-source/MY-PORTFOLIO.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd MY-PORTFOLIO
   ```

3. **Open `index.html`:**
   - Double-click `index.html` to open directly in any web browser, or
   - Use the VS Code **Live Server** extension.

---

## 🌐 Deploying to GitHub Pages

You can easily host this portfolio for free using **GitHub Pages**:

1. Go to your repository on GitHub: [`akshreyagupta28-source/MY-PORTFOLIO`](https://github.com/akshreyagupta28-source/MY-PORTFOLIO)
2. Click on **Settings** → **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Your portfolio will be live at `https://akshreyagupta28-source.github.io/MY-PORTFOLIO/` in a few moments!
